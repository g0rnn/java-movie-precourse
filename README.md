## 기능 목록

- 영화
    - [v] 하루에 여러 차례 상영될 수 있음
    - [v] 상영 시간은 영화의 상영 길이와 상영관의 운영 시간에 따라 정해짐

- 상영 시간.?

- 예매
    - [v] 여러 영화를 한 번에 예매할 수 있음
    - [v] 상영 시간이 겹치는 영화는 예매할 수 없음

- 좌석
    - [v] 행(알파벳)과 열(숫자)로 표시 ex. A1, C3, E4
    - [v] 좌석 등급에 따라 상이한 가격
        - (일반 좌석 - B등급), (E열 좌석 - A등급), (리클라이너 좌석 - S등급)
    - [v] 이미 예약된 좌석은 다시 선택할 수 없음
    - [v] 좌석은 A1 ~ H8 까지 존재함 (new)

- 할인
- 할인
    - [ ] 다음 조건을 만족해야 적용됨
        - 무비데이 조건: 매월 10일, 20일, 30일에 영화 10% 할인
        - 시간 조건: 11시 이전 or 20시 이후엔 2,000원 할인
        - 동시 적용 가능, 무비데이 할인이 우선 적용

- 포인트
    - [ ] 예매 금액에서 직접 차감
    - [ ] 포인트를 적용하면 결제 수단에 따라 추가 할인이 적용 (신용카드 5%, 현급 2%)

- 결제
    - [ ] 신용카드와 현금 결제 가능
    - 포인트와 할인이 동시 적용? and 순서는? (new)

- 영화와 상영 시간을 고른 뒤 좌석을 선택
